# Як долучитися

## Збірка

```sh
git clone https://github.com/dmitthedazed/SvitloYE.git
cd SvitloYE
./gradlew testDebugUnitTest assembleDebug
```

Потрібні JDK 21 і Android SDK. Мінімальна версія Android: 8.0 (API 26). GitHub Actions запускає ті самі тести на кожен пуш.

## Правила

- Графіки беруться з сайту Житомиробленерго (ztoe.com.ua). Не додавайте інших джерел даних без обговорення в issue.
- Тексти інтерфейсу українською.

## Pull requests

Невеликі й про щось одне. Для змін в інтерфейсі додайте скриншоти, для змін у розборі графіка напишіть, на якій черзі перевіряли.

## Помилки

[Відкрийте issue](https://github.com/dmitthedazed/SvitloYE/issues/new/choose): номер черги, версія застосунку і що пішло не так.
